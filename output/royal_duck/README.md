# 왕관 오리 + 리깅 망토

## 파일

- `RubberDuck_RoyalCape.blend`: 편집 가능한 Blender 원본. 기존 오리와 왕관, 망토, 칼라, 장식, 리깅, 애니메이션, 미리보기 조명이 들어 있습니다.
- `RubberDuck_RoyalCape.fbx`: 게임용 오리/왕관/망토 메시와 리깅, 애니메이션. 카메라, 조명, 바닥, 숨겨진 원본 메시 복제본은 제외했습니다.
- `Cape_Red_BaseColor.png`, `Collar_Ivory_BaseColor.png`, `Crown_Gold_BaseColor.png`: 1024 x 1024 텍스처. blend에는 패킹하고 FBX에도 포함했습니다.
- `RubberDuck_RoyalCape_preview.png`, `RubberDuck_RoyalCape_back.png`: 앞·뒤 렌더.
- `Cape_Breeze_preview.webp`: 기본 흔들림 애니메이션 미리보기.
- `validation.json`: 원본 형상 보존, 리깅 가중치, 애니메이션 및 FBX 재가져오기 검사 기록.

## 모양과 리깅

기존 오리 및 왕관의 정점·면·위치는 유지했습니다. 망토만 추가했습니다. 참고 이미지의 붉은 망토, 밝은 칼라, 금색 여밈을 짧고 둥근 오리 체형에 맞췄습니다. 원본 왕관 오리 파일을 덮어쓰지 않았습니다.

`Cape_Rig`는 루트 본 1개와 3단 본 체인 7개, 총 22개 본으로 구성되어 있습니다. 망토와 금색 테두리는 같은 가중치 방식으로 움직이며, 칼라와 여밈 장식은 루트에 고정되어 있습니다. 정점당 최대 4개 본의 영향을 받습니다.

Blender에서 `Cape_Rig`를 선택하고 Pose Mode로 들어가 `Cape_01_01` ~ `Cape_07_03` 본을 조절할 수 있습니다. 기존 애니메이션이 자세를 제어하므로 직접 포즈를 편집하려면 별도 액션을 만들거나 현재 액션을 복제해 수정하세요.

## 애니메이션

- 액션: `Cape_Idle_Breeze_4s`
- 속도: 30 fps
- 구간: 1 ~ 121 프레임 (4초, 마지막 프레임은 시작과 동일)
- 1프레임은 기본 자세. 타임라인을 재생하면 망토가 부드럽게 흔들립니다.

본에 저장된 반복 애니메이션입니다. 이동 속도·바람·장애물에 자동으로 반응하는 실시간 천 물리는 추가하지 않았습니다. 제공한 기본 애니메이션을 벗어나 크게 포즈를 바꾸면 오리와의 관통 여부를 다시 확인해야 합니다.

## 가져오기

Blender 5.2.2 LTS에서 제작했습니다. FBX는 -Z 전방 / Y 위쪽으로 내보냈습니다. Blender로 재가져올 때 `Animation Offset`을 0으로 설정하면 원본과 프레임 번호가 같습니다.

Unity에서는 FBX의 Rig를 Generic으로 사용하고, 애니메이션 클립의 Loop Time을 활성화해 반복 재생할 수 있습니다. Unity 내 재생은 이 작업에서 검증하지 않았습니다. 재질이 자동으로 연결되지 않으면 포함한 PNG를 해당 재질의 Base Map에 넣으세요. Blend와 FBX를 같은 Unity Assets 폴더에 모두 넣으면 같은 모델이 중복 임포트될 수 있으니 게임 프로젝트에는 FBX를 사용하고 blend는 작업 원본으로 보관하는 편이 간단합니다.
