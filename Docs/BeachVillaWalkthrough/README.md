# Beach Villa 1인칭 검사 환경 — 2026-09-27

기존 Beach Villa 씬에 `Beach Villa - Walkthrough`를 추가하고 기존 Main Camera를 자식으로 연결했다. 새 씬·카메라·조명은 만들지 않았다. 오리 상호작용이나 최종 게임 플레이어가 아닌 맵 검사 전용 이동 기능이다.

## 사용

Beach Villa에서 Play를 누른 뒤 Game 화면을 클릭한다.

- WASD: 이동, 마우스: 시점, 왼쪽 Shift: 빠르게 이동.
- Esc: 마우스 해제. 다른 창으로 전환해도 잠금을 해제한다.
- F1: 수영장 테라스, F2: 입구, F3: 실내, F4: 실내 뒤쪽, F5: 2층, F6: 2층 앞쪽.
- R: 마지막 검사 지점 복귀. 맵 아래로 추락하면 같은 지점으로 자동 복귀.
- H: 조작 안내 숨김/표시.

검사 순서: 테라스 → 외부 계단 → 입구 → 실내 → 실내 계단 → 2층 → 앞쪽 발코니. F키는 점검 위치로 순간 이동하며, 이 경로가 연속해서 걸어갈 수 있다는 검증을 대신하지 않는다. 바닥 판정에 사용하는 Roof 이름은 에셋의 1층 천장 겸 2층 바닥 모듈이다.

## 수정과 비용 제한

- 높이 1.8m·반경 0.28m 캐릭터 충돌체 하나, 눈높이 1.65m, 계단 오르기 높이 0.3m, 경사 한도 45도.
- 걷기 2.6m/s, 빠른 이동 4m/s. 대각선 이동 속도를 정규화하고, 화면 끊김 때 이동 폭을 제한했다.
- 카메라 근거리 클립을 0.3m에서 0.08m로 줄여 가까운 가구가 잘리는 현상을 줄였다. 원래 카메라 위치·각도는 setup-validation.txt에 기록했다.
- 기존 활성 카메라 1개와 AudioListener를 재사용한다. 추가 렌더링 카메라·매 프레임 씬 검색·프로브 재베이크를 추가하지 않았다.
- 바닥 및 머리 공간 검색은 에디터 구성/검증 때만 실행한다. 런타임에는 캐릭터 이동과 입력만 갱신한다. 안내창에는 비용이 있으며 H로 숨길 수 있다.
- 런타임 FPS 개선 수치는 측정하지 않았다. APV·광원·그림자·기존 가구 배치는 유지했다.

## 검증 결과와 한계

- Unity 컴파일 및 Play 진입 확인.
- 최종 6개 지점 모두 1.8m 캡슐 여유 공간 검사와 중력 이동 검사 통과. 지점에서 바닥으로 내려가는 거리 약 0.02m.
- 최초 2층 앞쪽 지점이 난간 충돌면을 선택한 문제를 발견해 바닥 계열 표면 필터를 추가했다. 최종 위치는 checkpoint-validation.txt를 기준으로 한다. setup-validation.txt는 최초 구성 기록이다.
- Play 모드에서도 6개 지점 모두 접지 확인, 캐릭터 충돌체로 0.5초에 해당하는 전진을 모의 실행해 1.300m 이동 확인, 활성 카메라 1개 확인. 결과는 playmode-validation.txt에 있다.
- 시작 시점과 2층 시점 화면, 마우스 시점 변화와 잠금 해제를 확인했다. 자동화 키 입력으로 F키 전환을 끝까지 확인하지는 못했다. 런타임 전환 함수 직접 호출 검사는 키보드 입력 검증과 구분한다.
- 전체 동선의 계단·문·가구 사이 통과, 물속 처리, 실제 오리 집기, 전체 빛샘 검사, 1080p 빌드 성능은 남아 있다. 현재 Game View의 QHD 설정에서 본 화면은 1080p 성능 측정이 아니다.

재검증 메뉴: Rubber → Walkthrough → 2 Validate Checkpoints(편집 모드), 3 Play Mode Smoke Test(플레이 모드). 1 Configure and Validate는 최초 구성용이며 중복 생성을 차단한다.
