## 제안 콘셉트

수영장을 중심으로 이어지는 따뜻한 휴양 빌라. 낮에는 햇빛과 식물, 저녁에는 긴 그림자와 실내 조명, 밤에는 수영장과 창문 불빛이 공간을 안내한다.

바탕색은 아이보리·목재색, 보조색은 청록·식물의 초록으로 잡는다. 노랑은 러버덕의 식별색으로 사용하고 주변 노란 장식은 제한한다.

## 건물 구조와 동선

첫 제작은 단층으로 시작한다. 거실에서 테라스와 수영장이 보이도록 출입구와 창을 배치하고, 실내외를 한 바퀴 돌아 출발점으로 돌아오는 길을 만든다.

```text
입구 → 거실 ↔ 다이닝
         ↕        ↕
      테라스 ↔ 수영장 ← 반환 지점 후보
         ↕        ↕
      정원 길 ↔ 스파
```

초기 치수 제안: 거실 6×6m, 다이닝 4×6m, 테라스 8×3m, 수영장 구역 10×8m. 실제 모델 크기와 플레이어 충돌 크기에 맞춰 조정한다. 주요 보행 통로는 우선 1.2~1.5m 확보하고 오리를 들고 통과할 수 있는지 확인한다. 2층·침실·욕실은 첫 구역 검증 후 확장한다.

## 방과 가구 배치

| 구역 | 구성 | 보유 에셋 후보 | 러버덕 위치 후보 |
|---|---|---|---|
| 거실 | 러그 위 소파와 낮은 테이블, 창가 독서 자리 | Couch Group A, CouchTable, CarpetA, BookA, CouchTableLamp | 쿠션 옆, 테이블 아래 가장자리 |
| 다이닝 | 식탁 한 개와 의자, 식기 소그룹 | DiningTable, DiningChair, CoffeePot, Bowl | 의자 옆, 식기 뒤로 머리 노출 |
| 테라스 | 선베드와 사이드 테이블, 화분 | Lounger, SideTable Variant, TowelA, PottedPlantA | 접힌 수건 옆, 화분 뒤 측면 |
| 수영장 | 물가 접근로와 반환 지점 후보 | PoolA, PoolLadder, PoolLight | 사다리 근처 물가; 수영 없이 접근 가능한지 확인 |
| 정원 | 길을 감싸는 낮은 식재, 랜드마크 조명 | StoneboxLow, Shrub, Lantern | 화단 모서리, 랜턴 옆 |
| 스파 | 자쿠지 중심의 작은 휴식 공간 | Jacuzzi, SpaPavillon, TowelA | 자쿠지 외곽 턱, 수건 근처 |

배치 순서는 큰 가구 → 통로 확보 → 조명 → 오리 위치 → 작은 소품이다. 소품은 생활 흔적을 나타내는 2~3개 단위로 묶고, 모든 표면을 채우지 않는다. 문 여는 범위와 카메라 시야를 비워 둔다.

## 러버덕 숨김 규칙

첫 구역은 6마리로 검증한다. 쉬움 3마리, 보통 2마리, 어려움 1마리를 제안한다. 최종 수집 개수는 게임 기획에 맞춰 정한다.

- 쉬움: 입장 시 머리나 몸 대부분이 보인다. 첫 오리는 입구에서 자연스럽게 발견한다.
- 보통: 가구 옆으로 이동하면 보인다. 입구에서도 색이나 실루엣 일부를 단서로 준다.
- 어려움: 다른 방향에서 한 번 더 관찰해야 보인다. 접근 경로와 집기 가능 여부를 보장한다.
- 기본안은 걷기와 바라보기만으로 찾을 수 있게 한다. 앉기·점프·문 열기·수영이 필요한 은신처는 해당 기능이 확정된 뒤 추가한다.
- 불투명 물체 내부, 손이 닿지 않는 틈, 완전한 암흑, 충돌체 뒤에는 배치하지 않는다.
- 난이도는 발견까지의 관찰과 이동으로 조절한다. 작은 크기나 어둠만으로 어렵게 만들지 않는다.
- 위치별로 낮/밤 시인성, 접근성, 집기 거리, 반환 경로를 기록한다.

## 조명·환경·밤낮 연출

| 시간대 | 색과 분위기 | 안내 역할 |
|---|---|---|
| 낮 | 부드러운 중성 햇빛, 밝은 실내 간접광 느낌 | 창문과 수영장이 방향을 알려 준다 |
| 해질녘 | 주황빛 햇빛과 긴 그림자, 실내등 점등 | 실내와 실외의 온도 차이를 강조한다 |
| 밤 | 푸른 외부 채움광, 따뜻한 실내등, 청록 수영장 | 길·출입문·반환 지점을 읽을 수 있게 한다 |

처음에는 낮과 밤 두 상태를 먼저 완성한다. 같은 카메라 위치에서 비교해 모든 오리가 두 상태에서 발견 가능한지 검증한 뒤 시간 흐름을 연결한다.

움직이는 태양과 켜고 끄는 조명은 실시간 조명 중심으로 시험한다. 베이크된 조명은 미리 저장된 결과이므로 태양 회전이나 조명 끄기만으로 그 결과가 함께 바뀌지 않는다. 낮 조명이 밤에도 남는 문제를 확인하고, 최종 베이크·프로브 전략은 목표 기기와 성능 측정 후 선택한다.

그림자가 있는 조명은 주요 광원부터 적용한다. 반사, 물 표면, 유리, 밝게 빛나는 재질은 낮과 밤을 각각 확인한다. 안개와 Bloom은 시야 및 오리 윤곽을 해치지 않을 정도로만 사용한다.

기술 참고: [Unity 조명 모드](https://docs.unity.com/en-us/engine/6000.7/manual/lighting-overview/lighting-light-sources/components/configuring/light-modes). 개념 참고용 문서이며 세부 설정은 프로젝트의 6000.4 에디터에서 확인한다.

## 보유 에셋 사용 범위

사용자 지시에 따라 지금 다운로드한 에셋만 사용한다. 추가 검색·구매·다운로드는 진행하지 않는다. Modern Villa를 시각적 기준으로 삼고, 침대나 욕실 가구 등 보유 여부가 확인되지 않은 요소는 첫 제작 범위에서 제외한다. 러버덕 모델이 없다면 자체 기본 도형 마커로 위치만 표시한다.

보유 에셋 점검 항목: Unity 6/URP에서의 표시, 모델 스케일, 텍스처 크기, 충돌체, LOD, 기존 가구와 재질의 조화. 배포 전에는 보유 에셋 사용 권한과 팀 공유 조건도 확인한다.

기존 Modern Villa 원본은 유지한다. 프로젝트용 프리팹 변형과 자체 재질은 `Assets/_Project`에 둔다.

## 제작 순서와 완료 기준

사용자 추가 지시: 맵 확장 전에 [조명·성능 작업 기준](LightingPerformance.md)에 따라 작은 조명 시험 구역에서 낮밤과 성능을 검증한다. 매 작업마다 수정 내용·적용 최적화·검증 결과를 보고한다. 아래 제작 순서는 이 선행 검증을 반영하여 진행한다.

1. 데모 씬을 에디터에서 확인하고 사용할 건물과 가구를 선정한다.
2. `Assets/_Project/Scenes/Test`에 거실·테라스·수영장 시험 구역을 만든다. 기본 도형으로 크기와 연결을 먼저 확인한다.
3. 실제 프리팹으로 교체하고 6개 오리 위치를 표시한다. 이동과 수집 기능이 준비되기 전에는 위치 마커로 구분한다.
4. 낮/밤 조명을 각각 구성하고 같은 시점에서 비교한다.
5. 실제 플레이어로 충돌, 문 통과, 집기, 수영장 반환 경로를 확인한다.
6. 목표 기기에서 프레임 시간과 메모리를 확인하고, 검증된 구역을 실제 플레이 씬으로 확장한다.

완료 기준: 모든 오리에 합법적인 접근·수집 경로가 있고, 낮과 밤 모두 단서를 읽을 수 있으며, 주요 길이 가구로 막히지 않고, 목표 기기 성능 기준을 충족한다. 현재 첫 시험 씬과 위치 표식을 제작했으며 수집·반환 기능은 아직 연결 전이다.
