# Modern Villa 시간 흐름 연출

기존 Modern Villa 씬에 아침·정오·노을·밤의 라이트맵과 APV를 새로 베이크했다. 배치를 변경하지 않았으며 움직이는 문은 정적 베이크 대상에서 제외했다. 기존 문 테스트, 이동, 점프, 손전등은 유지한다.

## 사용법

Play를 시작하면 오전 07:00부터 시간이 흐른다. 기본값은 실제 10분에 게임 속 하루가 지나가는 반복 재생이다.

- T: 시간 흐름 정지/재개.
- N: 다음 주요 시간대(07:00 → 12:00 → 18:00 → 00:00)로 5초 동안 빠르게 진행.
- [ / ]: 한 시간 전/후로 즉시 이동하는 검토용 키.
- F: 손전등. E/O/P: 기존 문 테스트. Space: 점프.

Hierarchy의 `Modern Villa - Lighting Walkthrough`에 있는 `Villa Time Of Day`에서 `Day Length Seconds`를 바꾸면 하루 길이를 조절할 수 있다. `Hour`는 0~24시이며, 게임플레이 담당자는 `SetHour(float)`, `running`, `dayLengthSeconds`를 통해 실제 게임 시간과 연결할 수 있다. 현재는 로컬 테스트 시계이며 네트워크 동기화는 포함하지 않는다.

## 연출 구간

| 게임 시간 | 조명 |
|---|---|
| 00:00~05:00 | 어두운 밤 유지 |
| 05:00~07:00 | 밤 → 아침 |
| 07:00~12:00 | 따뜻한 아침 → 정오 |
| 12:00~15:00 | 정오 조명 유지 |
| 15:00~18:00 | 정오 → 붉은 노을 |
| 18:00~21:00 | 노을 → 밤 |
| 21:00~24:00 | 어두운 밤 유지 후 자정 반복 |

실제 천문 계산을 하는 시스템은 아니며 빌라의 분위기에 맞춘 연출 시간표다. 하늘 재질, 태양 방향·색·강도, 반사 강도, 벽·바닥의 라이트맵, APV 간접광을 함께 보간한다. 밤에는 태양과 반사 강도가 0으로 내려가며 고정 실내 조명과 손전등 중심의 밝기를 유지한다.

## 베이크와 최적화

- `Assets/_Project/Lighting/ModernVilla/TimeOfDay`에 4개 시간대의 라이트맵 저장. 각 상태는 directional atlas 2개이며, 실제 베이크에서 모든 상태의 Renderer/Terrain 라이트맵 좌표가 일치했다.
- APV 시나리오: Default(정오), Morning, Sunset, Night. 첫 베이크 이후 프로브 위치를 고정했다. 각 시나리오 CellData는 2,621,440바이트다.
- PC_RPAsset에서 APV Scenario Blending 활성화. L1 및 기존 프로브 공간 해상도 유지. 프레임당 블렌딩 셀은 4개로 제한하며 종료 시 이전 값으로 복원한다.
- 라이트맵은 GPU ComputeShader에서 혼합하고 GPU 복사로 적용한다. 게임 실행 중 CPU로 전체 텍스처를 읽거나 재베이크하지 않는다.
- 라이트맵 혼합은 기본 초당 최대 10회다. 정오/밤 유지 구간 또는 일시정지로 값이 같으면 혼합 작업을 생략한다. 태양과 하늘은 프레임마다 보간한다.
- 밉맵을 생성해 먼 거리 샘플링을 유지한다. 혼합 원본은 최상위 밉 레벨을 요청해 스트리밍으로 생길 수 있는 흐릿함을 줄인다.
- 태양은 Mixed/Baked Indirect 방식의 실시간 그림자, 고정 실내등은 Baked 유지. 매 프레임 실내등 그림자를 생성하지 않는다.
- 런타임 버퍼를 재사용하고 비활성화 시 해제한다. 4개 원본 상태와 출력 버퍼를 유지하므로 이전의 단순 낮/밤 교체보다 텍스처 메모리는 증가한다. 측정값은 playchecks.txt 참조.

APV 시나리오 블렌딩은 프로브 조명을 보간하는 Unity 기능이다. 정적 라이트맵은 별도의 GPU 혼합을 구현했다. 참고: [Unity 공식 문서](https://docs.unity3d.com/kr/6000.0/Manual/urp/probevolumes-bakedifferentlightingsetups.html).

## 검증 범위

`bake.txt`: 정오 19.4초, 아침 14.3초, 노을 14.2초, 밤 13.5초 베이크 완료. `playchecks.txt`: 시간별 상태, APV 혼합 계수, GPU 라이트맵 중간값, 재생/정지 프레임 측정, 자정 반복, 오류 기록.

Game 화면에서 07:00, 12:00, 16:30, 18:00, 19:30, 00:00을 캡처했다. 현재 편집기 GameView는 2560×1440이다. 이 검사는 사용자 PC의 편집기 측정이며 독립 실행 빌드의 1080p/60FPS 보장이나 최소 사양 판정은 아니다. 카메라 추가 렌더링 없이 정상 GameView에서 캡처했다.

최종 검사: 런타임 오류 0개, GPU 중간값 최대 RGB 오차 0.0001220703(half 정밀도 범위). 시간 정지 시 180프레임 동안 라이트맵 갱신 0회, 시간 재생 시 20회였다. 정지 중앙값 12.12ms / p95 14.27ms, 재생 중앙값 11.91ms / p95 13.80ms였다. 두 값의 작은 차이는 편집기 측정 변동으로 보며 성능 향상으로 해석하지 않는다. 혼합 출력 및 작업 버퍼의 Unity 보고 메모리는 71,398,272바이트(약 68.1MiB)이며 원본 시간대 텍스처/APV 메모리는 이 수치에 포함하지 않는다.

제약: 반사 프로브는 정오 베이크 큐브맵을 사용하고 시간대에 따라 강도를 줄인다. 노을/밤 전용 반사 큐브맵 혼합은 구현하지 않았다. 4개 베이크의 간접광 보간이므로 모든 중간 태양 위치를 실시간 GI로 재계산하는 것과는 차이가 있다. 동적 문·장난감에 의한 간접광 차폐 변화는 다시 베이크되지 않는다.

작업 전 디스크 씬과 작업 시작 시 씬은 이 폴더의 `.backup` 파일로 보관했다. 기존 APV 파일 백업은 `Library/VillaTimeBackup-20260928-154733`에 있으며 기존 Verified 라이트맵도 유지했다. 재베이크 메뉴: Rubber > Time Of Day > Bake Four Lighting States. 검사 메뉴: Rubber > Time Of Day > Run Playback Checks.
