# Modern Villa 낮·밤 조명 및 테스트

기존 `Assets/Modern Villa/Scenes/Modern Villa.unity`에 적용했다. 기존 건물·가구·식물 배치는 유지했다. 테스트 카메라만 눈높이 1.65m의 이동 리그에 연결했다. 변경 전 씬은 `BeforeLighting.unity.backup`에 보관했다.

## 조명과 최적화

- 낮과 밤을 각각 베이크했다. 각 모드에 방향성 라이트맵 2장(최대 1024), 별도 APV Default/Night 데이터를 사용한다.
- 고정 실내 조명 20개와 기존 Point Light는 Baked로 전환했다. 햇빛은 Mixed/Baked Indirect, 테스트 손전등은 실시간 Spot Light다. 고정 전등의 실시간 그림자 비용을 제거했다. 이동하는 오리는 APV의 베이크된 빛을 받지만 고정 전등에 의한 실시간 그림자는 생성하지 않는다. 손전등은 실시간 그림자를 만든다.
- 실시간 GI를 끄고, 라이트맵 밀도 40→16 texels/m, 직접광 32/간접광 256/환경광 128 샘플을 사용했다.
- 작은 소품·식물·가죽 소파 등 527개 렌더러는 APV로 조명을 받는다. APV는 L1, 기존 Low 메모리 예산, 시나리오 블렌딩 없이 전환한다. 실내 최저 간격 0.75m, 실외 2.25m로 배치했다.
- 기존 URP의 SRP Batcher, LOD, 그림자 거리 설정은 유지했다. 이번 변경으로 다른 씬의 렌더 파이프라인을 수정하지 않았다.
- 밤에는 태양과 환경 반사를 끄고 환경광을 매우 낮춘다. 전등 주변의 베이크된 직접광·간접광은 유지한다. 낮의 반사 프로브가 밤을 밝히지 않도록 밤에는 프로브 강도도 0으로 전환한다. 밤 전용 정적 반사 큐브맵 전환은 구현하지 않았다.
- 소파의 과도한 흰 부분은 라이트맵 오류가 아닌 원본의 발광 띠였다. 이 씬의 16개 렌더러에만 따뜻하고 약한 발광 재질을 적용하고 간접광을 다시 베이크했다. 원본 공유 재질은 유지했다.
- 낮/밤의 라이트맵 UV 배치가 달라지는 렌더러만 정적 배칭에서 제외해 전환 시 잘못된 UV 사용을 방지한다.

## 실행 및 조작

Modern Villa 씬을 열고 Play를 누른 뒤 Game 화면을 클릭한다.

- WASD 이동, 마우스 시점, Shift 빠르게 이동
- Space 점프(목표 높이 1m), 공중 재점프 차단, 천장 충돌 시 상승 중지
- N 낮/밤, F 손전등
- F1~F8: 테라스 / 식당 / 서재 / 독서 공간 / 거실 / 조식 공간 / 스튜디오 / 별채 휴식 공간
- R 현재 체크포인트로 복귀, H 도움말, Esc 마우스 해제

기존 수집·네트워크 플레이어와 별개인 조명 검수용 이동 기능이다. 점프 기능을 실제 게임 플레이어에 통합한 것은 아니다.

## 검증과 한계

`bake.txt`: 베이크 완료 및 라이트맵/APV 생성 기록.
`playchecks.txt`: 8개 위치 접지, 점프, 전진, 낮/밤/손전등 및 카메라 수, 에디터 프레임 측정.
`0-*.png`, `1-*.png`, `4-*.png`: 1920×1080의 실제 Game View 캡처. 추가 촬영 조명이나 Camera.Render를 사용하지 않았다.

에디터에서 짧게 측정한 수치는 단독 실행 빌드의 60FPS 보장이나 최저 사양 검증이 아니다. 전체 경로의 충돌, 수집 동작, 멀티플레이 검증은 이 테스트에 포함되지 않았다. 실행 시 원본의 누락 스크립트 및 Terrain 나무 MeshCollider 경고가 남아 있어 별도 정리가 필요하다.

최종 검증(2026-09-29): 저장 후 씬 재열기 성공. 체크포인트 8곳 접지 성공. 점프 0.963m, 공중 재점프 False, 착지 높이 오차 0.000m. 전진 0.5초/1.3m. 낮·밤·손전등 9개 캡처 모두 1920×1080, 활성 카메라 1개, 라이트맵 2장, APV Default/Night 전환 확인.

RTX 5070 Laptop / Ryzen AI 7 350에서 3개 위치 × 낮/밤(밤에는 손전등 켬), 각 180프레임의 에디터 측정: 중앙값 7.36~9.69ms, 95백분위 8.78~10.63ms. 이 구간에서는 60FPS의 16.67ms 기준 이내였지만 단독 빌드나 전체 플레이의 성능 보장은 아니다.

최종 베이크: `Assets/_Project/Lighting/ModernVilla/Verified`. 사용하지 않는 중간 베이크는 씬 의존성 확인 후 `Library/ModernVillaLightingReviewArchive-20260929`에 보관했다. `Rubber > Modern Review > Bake Day and Night`는 이후 새 Bake 폴더를 만들어 다시 베이크한다. 검증은 Play 중 `Test In Play` 메뉴로 실행한다. 현재 베이크를 다시 실행할 필요는 없다.
