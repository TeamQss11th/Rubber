# VillaEstate 확장 작업 — 2026-09-20

> 과거 기록: 2026-09-22 사용자 요청으로 VillaEstate 씬은 삭제했다. 현재 작업은 기존 Beach Villa 씬에 오브젝트를 추가하는 방식이다. 아래 캡처와 수치는 삭제된 씬의 기록이며 현재 씬의 결과가 아니다.

현재 작업 씬: `Assets/_Project/Scenes/Main/VillaEstate.unity`. Unity에 열어 두었다. 원본 Modern Villa 씬의 가구가 있는 본관을 복사하고, 기존 에셋으로 별관과 수영장·정원을 확장했다. 원본 씬 파일은 수정하지 않았다. 이전 시험 씬의 저장되지 않은 상태는 `VillaLightingStudy_BeforeExpansion.unity`에 보존했다.

## 크기와 수정 내용

| 비교 | 원본 Modern Villa | 확장 VillaEstate |
|---|---:|---:|
| 시설 배치 외곽 | 약 30.75 × 35.01m | 72 × 80m |
| 외곽 직사각형 면적 | 약 1,077㎡ | 5,760㎡ |
| 배경 대지 | 100 × 100m | 120 × 110m |

시설 외곽 면적 기준 약 5.35배다. 실내 연면적 또는 순수 보행 면적의 배수가 아니다. 모델 자체를 확대하지 않고 원래 가구 크기를 유지한 채 공간과 목적지를 추가했다.

- 북쪽: 원본 가구가 배치된 본관과 기존 부속 공간.
- 서쪽: 라운지·독서실·게임 라운지용 방 3개.
- 동쪽: 다이닝·티룸·정원 라운지용 방 3개.
- 각 새 방은 12 × 10m이며 양방향 출입구와 가구 배치를 갖는다. 방 이름은 디자인 용도이며 게임이나 차 마시기 기능은 구현하지 않았다.
- 중앙: 큰 수영장, 선베드 10개와 차양.
- 남쪽: 입구 산책로, 반환 위치 후보, 휴식 파빌리온 2곳.
- 양쪽 정원섬 10곳, 새 방의 오리 위치 표식 6개. 표식은 수집 가능한 러버덕이 아니다.

## 적용한 최적화

- 국소 조명 후보 27개 중 플레이어 22m 이내 가까운 8개만 켠다. 낮에는 모두 끈다.
- 국소 그림자는 Spot 최대 2개만 사용한다. 태양/달은 동일한 Directional Light 1개를 재사용한다.
- 가까운 조명 선택을 초당 5회 갱신하고, 재사용 배열로 갱신 중 배열 할당을 피한다. 원거리 5m 구간에서 밝기를 줄인다.
- 새로 배치하는 프리팹 내부의 중복 조명과 Reflection Probe를 끈다. 원본 씬에서 상속된 조명·반사 프로브도 껐다.
- 물은 별도 반사 카메라가 없는 단순 표면이다. 작은 장식에는 충돌을 생략하고, 고정 프리팹에는 배칭용 정적 플래그를 설정한다. 실제 드로우콜 감소량은 미측정이다.
- 기존 PC 렌더 품질은 이번 확장 때문에 낮추지 않았다. 실시간 태양에 맞지 않는 원본 라이트맵 연결은 새 씬에서 해제했다.

## 확인 결과와 제한

- Unity 컴파일 및 씬 생성, 낮·밤 입구/실내/조감 캡처 완료.
- 활성 Renderer 2,198개, 누락되거나 지원되지 않는 재질 슬롯 0개.
- 0.5m 격자 20,961개에서 바닥과 반경 0.28m 캡슐 여유를 검사했다. 입구에서 새 방 6곳 내부까지 모두 연결된다. 원본 본관의 계단·2층 및 실제 이동 조작 전체를 검증한 것은 아니다.
- 낮·저녁·밤 969개 위치/시간대 조건에서 국소 조명 최대 8개, 국소 그림자 최대 2개, 상한 위반 0건.
- 조감 이미지만 배치 판독을 위해 안개를 제외했다. 입구/실내 이미지는 플레이 안개 설정을 유지한다.
- **1920×1080 / 60FPS는 목표이며 이 확장 씬의 실제 FPS·GPU 시간은 아직 측정하지 않았다.** 이전 VillaStudy 실행 파일/벤치마크 결과를 이 씬의 성능으로 사용하면 안 된다.
- 물은 임시 표현이고, 실내 낮 간접광과 소파의 밝은 재질 띠는 후속 조정 대상이다. 조명 선택 경계의 전환, 본관 동선, 수집 상호작용도 후속 검증이 필요하다.
- 캡처 중 Unity Enlighten의 emissive-buffer 재초기화 경고가 기록되었다. 렌더 및 파일 생성은 완료했지만 경고 원인은 아직 해결하지 않았다.
