# 모던 빌라 바닥·계단 충돌 검사

2026-09-29, `Assets/Modern Villa/Scenes/Modern Villa.unity`에 적용.

## 수정한 내용

- 별채의 완전히 중복된 바닥 1개 비활성화. 원본 오브젝트는 보존.
- 겹친 사각 바닥 23개의 가로/세로 범위 정리. 기존 바닥 높이와 바깥 경계는 유지.
- 뒷마당 모서리의 부분 겹침은 기존 바닥 타일을 두 조각으로 배치하여 빈틈 없이 정리.
- 수영장 계단의 누락된 MeshCollider 추가.
- 수영장 테두리·곡선 모서리 등 36개 표면에 실제 메시와 일치하는 충돌면 추가. 기존 테두리 BoxCollider만으로 덮이지 않던 부분 보완.
- 뒤쪽 수영장 계단 끝에서 바닥까지 약 1.3m 낙차가 있어 올라올 수 없던 곳을 기존 StepBlock 프리팹 7개로 연결. 단 높이 18.5cm, 디딤판 깊이 30cm, 폭 3.4m. 재질은 기존 수영장 바닥 재질 사용.
- 수영장 바닥과 같은 평면에 있던 조명 기구 메시 6개를 1cm 올려 겹침 완화. 광원 설정 변경 없음.
- 별채 계단 끝의 벽은 정상 구조로 확인. 옆으로 돌아 나가는 경로를 검사했으며 벽을 제거하지 않음.

## 검증 결과

현재 테스트 플레이어와 같은 CharacterController 사용: 높이 1.8m, 반지름 0.28m, 최대 단차 0.3m, 경사 제한 45도.

실행 중인 Unity의 편집 모드 물리 엔진에서 임시 테스트 캡슐로 검사했고 테스트 오브젝트는 제거했다. 플레이 모드에서는 수영장 계단과 별채 계단을 화면 캡처로 확인했다. 자동 검사는 유한 간격 샘플링이며 모든 가능한 이동·점프·문 상태를 수학적으로 보장하지 않는다. 17개 막힘은 추락과 구분했으며, 가구·벽·문 등의 모든 이동 경로를 이번 작업에서 변경하지는 않았다.

## 유지 및 후속 사항

- 성능 최적화, 그림자 설정, 낮/노을/밤 전환 로직 변경 없음.
- 바닥 형상을 변경했으므로 최종 배치 확인 후 시간대별 라이트맵/APV 재베이크 필요. 이번 작업에서 재베이크하지 않음.
- 바닥 겹침·충돌면 누락은 발견하고 수정했지만, 이것이 이전 Unity 프로세스 크래시의 원인이었다는 증거는 없음.
- 기존 Missing Script 및 Terrain 나무 콜라이더 경고는 별도 문제로 남아 있음.

## 재현 자료

- `BeforeRepair.unity.backup`: 작업 전 저장 씬 백업. 자동 복원은 하지 않음.
- `repairs.txt`: 적용 기록.
- `summary.txt`, `surfaces.tsv`, `colliders.tsv`, `missing-support.tsv`: 표면 및 충돌면 조사.
