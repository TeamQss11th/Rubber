# 비치 빌라 밤 분위기 미리보기

**폐기된 촬영 방식의 기록:** 이 폴더의 이전 PNG는 야간 검증 자료로 사용하지 않는다. 수동 렌더링 과정에서 낮 이미지가 남는 현상과 D3D12 오류가 확인됐고 뒤이어 에디터가 크래시했다. 해당 촬영 코드는 제거했다. 최신 작업과 검증은 `../BeachVillaDarkNight/README.md`를 참고한다. 아래 내용은 이전 시도 기록이다.

기존 Beach Villa 씬에서 촬영한 1920×1080 이미지다. 별도 씬이나 외부 에셋을 만들지 않았다.

- 변경: 촬영 중에만 기존 주광원을 푸른 달빛(강도 0.09)으로 변경하고 기존 실내·외부 국소등을 따뜻한 색으로 조정했다. 하늘 노출과 환경 반사 강도를 낮췄다.
- 낮 베이크 제거: 촬영 중 Renderer 라이트맵 인덱스를 해제하고 APV 강도를 0으로 두어 낮 데이터 대신 약한 환경광을 사용했다. 이는 야간 GI를 베이크한 결과가 아닌 조명 구도 미리보기다. 실내 반사광·접촉부 밝기는 최종 베이크에서 달라진다.
- 비용 제한: 기존 광원 11개 재사용, 새 그림자 광원 없음, 기존 카메라로 촬영. 실제 60FPS 성능 검증은 수행하지 않았다.
- 복원: 촬영 종료 시 광원·하늘·환경광·라이트맵 인덱스·카메라 상태를 복원한다. 씬과 낮 APV 데이터를 저장하거나 재베이크하지 않는다.
- 출력: exterior-day.png, exterior-night.png, interior-night.png.

다시 촬영: Rubber → Night Preview → Capture Day and Night. 플레이 모드 밖에서 기존 Beach Villa를 열고 실행한다.

최종 야간 구현에서는 정적 라이트맵과 APV 모두 밤의 간접광에 맞추고, 손전등을 켜고 끈 상태의 가시성과 성능을 검증해야 한다.
