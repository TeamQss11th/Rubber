# Modern Villa 슬라이딩 문

2026-09-29. 기존 Modern Villa 씬의 문 8개에 적용. 외부 에셋 원본 프리팹은 변경하지 않고 씬 인스턴스에 적용했다.

## 테스트

Modern Villa 씬에서 Play 후 Game 화면에 초점을 둔다.

- E: 카메라에서 3m 이내 가장 가까운 문의 열기/닫기 전환. 테스트 전용이며 시선 판정/벽 차폐 판정을 하지 않는다.
- O: 모든 문 열기.
- P: 모든 문 닫기.
- 개별 문을 선택하면 Villa Sliding Door Inspector의 Open / Close / Toggle 버튼으로도 테스트 가능하다.
- N: 기존 낮/밤 전환. F: 기존 손전등.

유리 미닫이문 5개는 로컬 왼쪽(-X)으로 문짝 가로 폭의 2/3만큼 이동한다. 일반 문 3개는 기존 에셋의 경첩 피벗을 중심으로 실내 방향으로 90도 회전한다. 본관/별채 외부문은 동쪽 실내로, 별채 2층 실내문은 북쪽 침실로 열린다. 완전 개폐 시간은 2초이며 시작과 끝에서 부드럽게 감속한다. 이동 도중 반대 명령도 허용한다. 동일 명령을 반복해도 이벤트를 중복 발생시키지 않는다.

## 변경과 최적화

- 유리문 5개, 외부문 2개, 실내문 1개. 손잡이 및 자식 유리는 문과 함께 이동한다.
- 유리문 문틀의 통로 전체를 막던 BoxCollider를 비활성화하고 실제 문틀 메시와 고정 유리에 정적 MeshCollider를 적용했다. 움직이는 문은 단순 BoxCollider와 Kinematic Rigidbody를 사용한다.
- 문 이동 계산은 작동할 때만 실행하며 완료하면 해당 컴포넌트의 FixedUpdate를 중단한다. 물리 보간으로 화면의 움직임을 부드럽게 한다.
- 움직이는 Renderer 15개를 static batching/정적 베이크 대상에서 제외하고 프로브 조명을 사용한다. 밤 라이트맵 바인딩에서도 제외했다.
- 테스트 입력은 별도 VillaDoorTestControls 컴포넌트에 분리했다. 매 프레임 장면 전체를 검색하지 않고 키를 누른 때에만 저장한 문 목록을 검사한다.
- 건물, 가구, 커튼의 배치를 변경하지 않았다. 성능 수치/FPS는 이번 작업에서 측정하지 않았다.

## 담당자 연결

게임플레이 담당자는 VillaSlidingDoor.Open(), Close(), Toggle(), SetOpen(bool)을 호출하면 된다. 플레이어 입력, 레이캐스트, 상호작용 UI, 멀티플레이 상태 동기화는 이 컴포넌트와 분리되어 있다. 실제 플레이어 연결 시 테스트 입력 컴포넌트를 제거하거나 비활성화한다.

Inspector UnityEvent: onOpening / onOpened / onClosing / onClosed. 시작과 완료를 구분하며 완료 이벤트는 목표 지점 도착 시 실행된다. TargetOpen과 Progress로 현재 목표와 개폐 정도를 조회할 수 있다. 이동 도중 목표가 바뀌면 이전 목표의 완료 이벤트는 발생하지 않는다.

## 검증 및 남은 제약

playchecks.txt: 8개 문 전체의 목표 거리/원위치 오차는 출력 정밀도 0.000000m, 손잡이 상대 이동 오차 0.000000m. 반복 요청, 중간 반전, 열림/닫힘 이벤트와 유휴 상태를 확인했다. 밤 전환 뒤 모든 문은 lightmapIndex=-1, static batch=False였다.

반지름 0.28m의 플레이어 크기 캡슐을 열린 통로로 검사했다. 5개는 검사 경로에 충돌이 없었다. 다음 3개는 제한이 있다. 이 검사는 전체 플레이어 이동 경로를 완주한 테스트는 아니다.

- 별채 2층 실내문: 이전 미닫이 방식에서는 0.4261m만 열려 좁았다. 후속 변경으로 경첩을 기준으로 90도 회전하도록 수정했다. 회전 후에도 현재 반지름 0.28m 캡슐의 중앙 통과 경로는 열린 문짝 Collider와 닿는다. 문폭과 손잡이를 포함한 두께에 비해 여유가 부족하므로 통로 확대 또는 충돌 형상 조정이 별도로 필요하다.
- 별채 2층 Window Door: 기존 dining chair (2)가 검사 경로와 겹친다.
- 별채 2층 Window Door (1): 기존 Curtain이 검사 경로와 겹친다.

닫힐 때 플레이어나 장난감이 끼는 것을 감지하여 자동 재개방하는 기능은 구현하지 않았다. 현재는 개폐 이벤트 테스트용이다. 일반 문은 Kinematic Rigidbody.MoveRotation으로 회전하며 경첩 위치가 유지된다. 별도 Animator나 물리 경첩 시뮬레이션을 추가하지 않았다. 기존 이벤트와 씬 연결을 유지하기 위해 컴포넌트 파일명 VillaSlidingDoor는 유지했으며 Opening Style에서 Sliding/Hinged를 구분한다.

기존 낮/밤 베이크 파일은 유지했다. 문 이동에 맞춰 기존 베이크에 기록된 차광/간접광이 실시간으로 재계산되지는 않는다. 최종 이동거리와 배치를 검토한 뒤 정적 문 차광을 제거한 낮/밤 라이트맵 및 APV 재베이크가 필요하다.

설정 전 씬은 BeforeDoors.unity.backup에 보관했다. 설치 기록은 installed.txt, 반복 검사 메뉴는 Rubber > Modern Doors > Run Play Checks에 있다.

일반 문 회전 변경 직전은 BeforeHingedDoors.unity.backup으로 보관했다. hinged-installed.txt에 일반 문 3개의 경첩 위치와 부호 있는 각도를 기록했다. 최신 playchecks.txt에서는 일반 문 3개의 위치 및 회전 오차가 모두 출력 정밀도 0이며, 기존 유리문 5개도 통과했다. 이동/회전 완료, 복귀, 반전, 밤 조명 바인딩을 확인했고 성능 측정을 새로 수행하지는 않았다. 기존 installed.txt의 모든 문 미닫이 기록은 최초 설치 당시의 기록이다.
