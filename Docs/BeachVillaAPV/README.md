# Beach Villa APV 1차 적용 — 2026-09-23

기존 `Assets/Modern Villa/Scenes/Beach Villa.unity`에 적용했다. 새 씬은 만들지 않았다. 이번 범위는 **낮 간접광 APV 구성·베이크·화면 검증**이다. 밤 시나리오 및 낮밤 블렌딩은 아직 구현하지 않았다.

## 변경

- 현재 PC_RPAsset의 Light Probe System을 APV로 변경했다. 이 파이프라인을 공유하는 다른 씬에도 시스템 선택은 영향을 준다. Beach Villa만 Baking Set에 등록했다.
- 본관: 중심 (6.3, 3.5, 13), 크기 18×9×27m의 Local APV.
- 테라스·수영장: 중심 (2, 3, 12), 크기 44×12×60m의 Local APV.
- 베이크 설정과 결과는 `Assets/_Project/Lighting/BeachVilla`에 저장했다. 기존 건물의 라이트맵은 유지하고 APV만 베이크했다. Unity가 기존 LightingData 연결 메타데이터를 갱신할 수 있으며, 이는 라이트맵 전체 재생성을 의미하지 않는다.
- 광원 11개의 모드를 Realtime에서 Mixed로 바꾸고, 조명 설정은 Baked Indirect로 구성했다. 기존 밝기·색·그림자 설정은 유지했다. 직접광은 계속 실시간이며 간접광은 베이크한다.
- UV 오류가 난 라운지 의자 Renderer 4개는 APV를 받도록 변경했다. 해당 4개만 ContributeGI에서 제외했다. 원본 UV 자체를 고친 것은 아니다. 실시간 그림자·충돌은 유지하지만 이 의자들의 차폐·반사광은 새 베이크에 기여하지 않는 절충이다.
- Main Camera 하나만 활성화하는 이전 설정을 유지했다. 오리 자율 이동 로직은 추가하지 않았다.

## 비용 제한

- 200×200m 배경 지형 전체를 채우지 않고 플레이 구역의 Local Volume 두 개로 제한했다. 셀 정렬 때문에 실제 데이터 경계는 볼륨보다 확장될 수 있다.
- 최소 프로브 간격: 본관 0.75m, 외부 2.25m. 기하 구조에 따른 적응형 배치다. 모든 위치가 이 간격으로 균일하게 채워지는 것은 아니다.
- 런타임 SH는 L1, 프로브 풀은 Low. 직렬화 값 512는 풀 크기 enum이며 512MB라는 뜻이 아니다.
- 낮 시나리오 한 개(Default)만 사용하며 시나리오 블렌딩은 비활성화했다.
- Virtual Offset은 Unity 기본값을 유지했다. 벽 안에 놓인 프로브를 보정하는 기능이며 모든 빛샘을 자동으로 없애준다는 뜻은 아니다.
- GPU/FPS 개선은 주장하지 않는다. APV 샘플링은 추가 비용이 있으므로 1080p 60FPS는 빌드에서 별도 측정해야 한다.

## 검증 방법

`bake-status.txt`에서 HasBakedData=True 여부를 확인했다. `validation.txt`와 캡처는 같은 위치의 회색 구체에 APV 강도 0(환경광으로 대체)과 1을 적용해 비교한 것이다. 다른 조명 설정은 바꾸지 않았다. 중앙 80×80 영역의 RGB 차이는 기능 적용 여부를 확인하는 값이며, 성능이나 전체 화질 점수가 아니다.

세 지점은 본관 실내, 입구, 수영장 주변이다. 임시 구체·카메라·Volume은 검증 후 제거했다. 처음 실내 구체가 식탁 의자에 가려진 문제를 확인하고 위로 옮겨 다시 촬영했다.

## 남은 사항

- 기존 정적 라이트맵과 새 APV는 서로 다른 베이크 이력이다. 이번 작업은 기존 실내 전체의 베이크 일치성을 보장하지 않는다.
- 실제 러버덕 모델의 재질·크기·집기 위치에서 추가 확인이 필요하다. 검사용 구체는 실제 러버덕 검증을 대신하지 않는다.
- 벽 모서리·계단·가구 아래·2층 등 전체 경로 빛샘 검사는 남아 있다.
- 밤 간접광 시나리오와 태양·하늘·등의 시간대 제어는 후속 작업이다. 현재는 낮 데이터다.
- 베이크/스크립트 재로드 과정에서 Unity가 Persistent allocation leak 경고를 냈다. 출처 스택이 없는 에디터 경고이며, 플레이어 메모리 누수로 확정하지 않았다. 별도 추적이 필요하다.

재검증 메뉴: Rubber → APV → 4 Validate and Capture. 베이크 중에는 실행하지 않는다. 초기 구성 메뉴는 기존 APV가 있으면 덮어쓰지 않고 중단한다.
