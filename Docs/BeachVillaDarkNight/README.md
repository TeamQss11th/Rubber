# Beach Villa — 어두운 밤 검토

이 문서는 APV를 끄고 밝기를 검토했던 이전 단계의 기록이다. 이후 **Night APV 베이크와 테스트 손전등을 완료**했다. 현재 설정·제한·검증은 [최신 작업 기록](../BeachVillaNightBake/README.md)을 참고한다.

2026-09-27. 기존 Beach Villa 씬에서만 작업했다. 조명과 손전등 밖은 거의 보이지 않는 밝기를 목표로 한다.

## 실행

Beach Villa에서 Play를 누르면 밤으로 시작한다. Game View에 초점을 두고 N으로 낮/밤을 전환한다. 기존 이동·체크포인트 조작은 유지된다. 편집 화면은 낮으로 남는다.

메뉴 `Rubber > Night Preview`의 2/3번으로도 플레이 중 밤/낮을 선택할 수 있다. 4번은 현재 Game View를 한 번 저장한다. 새 씬이나 별도 렌더 카메라는 없다.

## 변경과 비용 제한

- 밤에는 방향광을 끄고 환경광을 거의 0으로 낮추며 환경 반사 강도를 0으로 설정한다. 하늘 노출은 0.001이다.
- 기존 국소등 10개를 유지하고 따뜻한 색으로 조정한다. 광원이나 그림자 광원을 추가하지 않았다. 기존 국소등은 그림자가 없으므로 벽 너머 빛샘은 추가 검토가 필요하다.
- 낮의 정적 라이트맵과 APV 간접광이 밤을 밝히지 않도록 밤 동안 라이트맵 연결을 해제하고 APV intensity multiplier를 0으로 덮어쓴다. 원본 베이크 에셋은 수정하지 않는다.
- 렌더러 목록 수집은 활성화 시 한 번, 밝기 설정 변경은 낮/밤 전환 시에만 수행한다. 매 프레임 전체 오브젝트 검색이나 반사 재촬영은 없다.
- 낮으로 전환하면 저장해 둔 라이트맵 연결, 방향광, 환경광, 반사와 광원 색을 복원한다.

현재 결과는 **밤의 기본 밝기를 확인하는 런타임 미리보기**다. 밤 전용 APV 베이크를 완성한 상태가 아니며 국소등의 간접 반사광도 아직 없다. APV 배율 0은 APV 메모리 해제를 의미하지 않는다. 손전등은 아직 추가하지 않았다.

## 실제 검증

Unity 6000.4.0f1의 일반 Play 모드에서 밤 진입 → Game View 촬영 → 낮 복원 → 촬영 → 플레이 종료를 확인했다. 이번 실행과 종료 확인에서 컴파일 오류, 예외, 이전 D3D12 오류의 재발은 관찰되지 않았다. 장기 안정성 보장은 아니다.

| 캡처 상태 | 정적 라이트맵 | 활성 방향광 | 활성 국소등 | 환경 반사 강도 |
|---|---:|---:|---:|---:|
| 밤 | 0 | 0 | 10 | 0 |
| 낮 복원 | 16 | 1 | 10 | 1 |

- [밤 실제 화면](night-gameview.png), [밤 상태](night-gameview-state.txt)
- [낮 복원 화면](day-gameview.png), [낮 상태](day-gameview-state.txt)

밤 화면에서 조명 없는 수영장·정원·외곽이 거의 검게 보이는 것을 확인했다. 물 표면 일부 밝은 점은 남아 있어 재질 검토 대상이다. 두 캡처 사이 카메라 방향이 달라 픽셀 비교 자료로 사용하지 않는다.

캡처 해상도는 당시 Game View의 2560×1440이다. **1920×1080/60FPS 빌드 성능 실측은 하지 않았다.**

## 크래시 대응

이전 Editor-prev.log에 D3D12 fence 대기 실패, command-state assertion 이후 `Unrecoverable D3D12 device error!`와 `Crash!!!`가 기록됐다. 수동 Camera.Render를 사용하는 이전 밤 촬영 작업과 관련됐을 가능성이 있으나 근본 원인을 확정하지 않았다. 로그에는 로컬/비로컬 GPU 메모리 부족이 아니라고 기록돼 있다.

BeachVillaNightPreview의 수동 Camera.Render/RenderTexture 촬영 경로를 제거했다. 현재 촬영은 일반 Play 모드의 ScreenCapture.CaptureScreenshot을 사용한다. 그래픽 API·드라이버는 변경하지 않았다. 기존 `_Recovery` 파일은 보존했다. 이전 BeachVillaNightPreview 폴더의 이미지는 검증 실패 자료이며 새 밤 결과로 사용하지 않는다.
